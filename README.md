# Samuel García

**Mathematics & Computer Engineering · MSc Artificial Intelligence**

I build and evaluate systems at the intersection of **machine learning, optimization and quantitative modelling**.

My background combines mathematical problem solving with software engineering, with a particular focus on **reproducible experiments, meaningful baselines and rigorous evaluation**.

Madrid, Spain · [LinkedIn](https://es.linkedin.com/in/jesussamuelgarciacarballo)

## Selected work

### [ADR-EDA](https://github.com/samugc/ADR-EDA)
Research software for dynamic multi-objective optimization using adaptive estimation of distribution algorithms, change detection and response strategies.

### [FinRAG](https://github.com/samugc/FinRAG)
Local RAG for financial documents with TF-IDF and MiniLM retrieval, Recall@k evaluation, source attribution and local Qwen generation.

### [QuantLab](https://github.com/samugc/QuantLab)
Reproducible quantitative research framework for portfolio experiments, backtesting, transaction costs and risk analysis.

### [SatelliteVision](https://github.com/samugc/SatelliteVision)
Satellite image classification on xView using Swin Transformers, imbalance-aware training, test-time augmentation and reproducible evaluation.

### [MarketNLP](https://github.com/samugc/MarketNLP)
Financial sentiment classification comparing TF-IDF + Logistic Regression with pretrained FinBERT under a shared evaluation pipeline.

### [StochasticDiffusion](https://github.com/samugc/StochasticDiffusion)
C++17 parameter estimation for stochastic diffusion models using numerical, evolutionary and memetic optimization.

## Research
